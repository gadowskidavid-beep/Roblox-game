## High-level view

`ConvertToGoldenPet` remains discoverable for rolling clients but always rejects without reaching `PetService`; `UseMachine` is the only public route into machine mutation. Gold requests are shape-checked and rate-limited before `MachineService` revalidates global/per-machine gates, world authority, pet eligibility, currency, RNG, rollback, and post-commit quest progress.

The client gives every prompt session and request a generation owned by `MachineClientSession`. Inventory close/toggle, navigation, `PromptHidden`, overlay Cancel, and prompt replacement revoke the same owner state, while completed-result timers retain the exact overlay they created and refuse to touch a replacement.

`ZoneService` retains exact server-created station references and revalidates model, anchor, zone, token, unlock, character, distance, and every configured prompt property. Authority is installed only when world initialization returns a callable validator; thrown initialization and non-function returns remain fail-closed.

The pure-Lua suites execute request generation, close invalidation, duplicate prevention, retry, prompt replacement, validator installation, thrown initialization, non-callable initialization, and prompt tampering. The generator embeds both new modules, and the place verifier compares every runtime source byte-for-byte rather than relying on source-name presence.

## Rolling compatibility without a legacy mutation path

The server creates both `ConvertToGoldenPet` and `UseMachine`, so an older client can finish startup discovery instead of blocking on a missing remote. The compatibility handler accepts no business input, returns only the migration error, and has no call to `PetService.convertToGoldenPet`; all runtime mutation delegates from `UseMachine` to `MachineService.attemptConversion` (**confirmed**).

The generic route accounts both cooldown buckets before inspecting caller-owned list data, accepts only bounded scalar identity plus a plain dense pet-ID list, and leaves price, chance, variants, station authority, and economic state server-owned. Rainbow's per-definition gate rejects before profile lookup, validator invocation, pet preparation, RNG, currency, or quest work.

## One revocation path owns every Gold client surface

`MachineClientSession.close` increments the generation and clears prompt, machine ID, identity token, and in-flight state. Pet Inventory close reaches `_requestGoldMachineCancel` directly and through `closeScreen`, with the second call becoming a no-op after the first revocation; generic `toggleScreen("PetInventory")` delegates to that same `closeScreen` path. Opening another screen also requests cancellation before navigation, overlay Cancel invokes the same callback, and `PromptHidden` calls the registered owner close directly (**confirmed**).

The owner callback closes both halves of the capability: `Main.client.lua` invalidates `MachineClientSession`, and `UIController` clears selection, multi-select mode, overlay references, and Gold-session visibility. Prompt replacement closes the previous generation before starting the next, while stale in-flight responses must match generation, prompt, machine ID, and token before reaching the UI.

## Delayed result cleanup cannot cross session generations

`showGoldMachineResult` captures `completedOverlay` before scheduling its three-second cleanup. The callback first requires `self._goldMachineOverlay == completedOverlay`; if cancellation or a later prompt has cleared or replaced that overlay, the old callback returns without destroying the current UI or clearing its references (**confirmed**).

## Exact prompt contract and fail-closed authority bootstrap

The station validator compares the exact registered Model, Anchor, Prompt, zone folder, zones folder, generated token, spawn CFrame, anchor dimensions, and model attributes. Its prompt predicate covers class/reference ancestry plus `Name`, `Parent`, `Enabled`, `HoldDuration`, `RequiresLineOfSight`, `MaxActivationDistance`, `ActionText`, and `ObjectText`; the executable tamper test mutates every configured prompt field and observes rejection before restoring it (**confirmed**).

`ZoneService.init` returns the private validator only after world generation and Gold station creation complete. `Main.server.lua` captures initialization with `xpcall` and passes its success bit and candidate to `MachineAuthorityBootstrap.install`; the helper installs only an actual function into a service exposing the expected setter. The executable bootstrap suite covers exact successful installation, initializer throw, nil, booleans, strings, tables, and numbers, and all failed cases leave authority absent (**confirmed**).

## Executable lifecycle coverage and source-complete artifact

`MachineClient.spec.lua` imports and executes `MachineClientSession`. It proves close invalidates an active request, duplicate begin is rejected, finish enables a higher-generation retry, replacement prompt/token ownership invalidates the old operation, and malformed/non-Gold starts fail closed; source assertions remain for entry-point/UI wiring.
